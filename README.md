# Keepsake — landing page

Адаптивний односторінковий лендінг дизайн-агенції **Keepsake** за макетом Figma «Keepsake — Responsive» (Desktop 1280, Tablet 768, Mobile 375, Mobile menu open, UI states).

**Демо:** https://chopykliliia-glitch.github.io/landing-keepsake/
## Технології

- HTML5 (семантична розмітка: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, `form`), один `h1`, послідовна ієрархія `h2` → `h3`.
- CSS3 без фреймворків і бібліотек: `css/reset.css` (скидання стилів) + `css/style.css`.
- Шрифти: Oswald (300/400/700), Open Sans (300/400/700), Dancing Script 700 з Google Fonts, `font-display: swap`.
- Іконки — інлайн-SVG (спрайт `<symbol>` + `<use>`).
- Зображення — WebP з `width`/`height` та `loading="lazy"`.
- JavaScript не використовується.

## Рішення

- **Дизайн-токени** (кольори, шрифти, шкала відступів `--space-*`, розміри, брейкпоінт-залежні значення) оголошені в `:root` і перевизначаються в медіазапитах, тому компоненти використовують лише змінні.
- **Mobile first:** базові стилі для 375 (працює від 320), далі `@media (min-width: 768px)` і `(min-width: 1280px)`. Контейнер має `max-width: 1100px` + поля, на ширших екранах центрується.
- **Розкладка:** Flexbox для всіх компонентів (послуги, статистика, клієнти, журнал, футер, шапка) з кількістю колонок через змінну `--cols`; сітка карток робіт теж на Flexbox (`flex-wrap` + `--cols`), без CSS Grid; картки тримають пропорцію через `aspect-ratio` (1 : 0.79 / 1 : 0.72).
- **Мобільне меню без JS:** `<button popovertarget>` + атрибут `popover` (Popover API). Бургер перетворюється на хрестик через `body:has(#site-menu:popover-open)`. Браузер сам синхронізує стан розкриття, `aria-expanded` і `aria-controls` додані в розмітку.
- **Фільтр портфоліо без JS:** приховані radio-інпути + `:checked ~` по `data-category`. Рядок чипсів на мобайлі прокручується горизонтально й виходить за правий край.
- **Load more works:** прихований checkbox + `label`, що показує додаткові картки (на мобайлі 5 → 9, на планшеті 8 → 9).
- **Ховер картки:** оверлей, бірюзовий «+», назва, коралова лінія, категорія. Той самий стан вмикається через `:focus-within`.
- **Форма підписки:** HTML-валідація (`type="email"`, обов'язковий чекбокс). Стан помилки через `:user-invalid` + `:has()`, помилка пов'язана з полем через `aria-describedby`; success реалізований через `:target` (форма надсилається на `#subscribed`). Реальної відправки немає.
- **Fixed header:** `position: fixed`; там, де підтримуються scroll-driven animations, висота зменшується до 64px при прокручуванні. Кнопка «вгору» завжди на екрані.
- **Доступність:** видимий `:focus-visible`, skip-link, `aria-label` на іконкових кнопках, `<label>` для email, `prefers-reduced-motion`.

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер, наприклад розширенням Live Server у VS Code.

## Структура

```
landing-keepsake/
├── index.html
├── css/reset.css
├── css/style.css
├── images/   (WebP)
└── fonts/    (шрифти підключені з Google Fonts)
```

## Примітки

- У макеті картки робіт і прев'ю журналу намальовані фігурами, тому зображення в `images/` — спрощені WebP-версії цих композицій. Замініть їх на реальні.
- Меню на мобайлі закривається хрестиком, Esc або кліком поза меню. Без JS воно не закривається автоматично після кліку по пункту.
